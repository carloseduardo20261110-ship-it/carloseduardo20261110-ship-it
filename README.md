### `SNAKE ANIMATION`

<div align="center">

<img src="https://raw.githubusercontent.com/carloseduardo20261110-ship-it/carloseduardo20261110-ship-it/output/snake.svg" alt="Snake animation of GitHub contributions"/>

</div>

**Para ativar a animação da cobrinha:**

Crie o arquivo `.github/workflows/snake.yml` no repositório do seu perfil e adicione o seguinte workflow:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest

    steps:
      - name: Generate contribution snake
        uses: Platane/snk@v3
        with:
          github_user_name: carloseduardo20261110-ship-it
          outputs: |
            dist/snake.svg

      - name: Publish animation
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Depois de salvar o arquivo, abra a aba **Actions** do GitHub, permita a execução dos workflows, se necessário, e execute `Generate Snake Animation` usando **Run workflow**. Após a primeira execução bem-sucedida, o arquivo `output/snake.svg` será publicado na branch `output`.
